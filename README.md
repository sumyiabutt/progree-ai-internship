Task 2 — Sentiment Classifier

Folder: "task2_sentiment_classifier/"

A multi-class NLP sentiment classifier using TF-IDF + Linear SVM. The project includes custom preprocessing with stop-word removal and rule-based lemmatization.

Evaluation: Accuracy, F1-score, and 5-fold cross-validation.

Run:python sentiment_classifier.py

Task 3 — Pathfinding Agent

Folder: "task3_pathfinding_agent/"

An A* heuristic pathfinding agent implemented from scratch with a binary heap and benchmarked against Dijkstra's algorithm across three grid mazes with different sizes and obstacle densities.

The project tracks nodes expanded, runtime, and path optimality.

Run: python pathfinding_agent.py

Task 4 — Computer Vision Pipeline

Folder: "task4_cv_pipeline/"

A real-time-style object detection and segmentation pipeline using OpenCV.

Pipeline:

"Gaussian Blur → Adaptive Thresholding → Contour Extraction → Bounding Boxes + Live Count"

Since the project was developed in a sandboxed environment without camera/internet access, a synthetic video stream was used instead of a real camera feed. The pipeline can be adapted to "cv2.VideoCapture()" input.

Run:python cv_pipeline.py

Requirements

- Python
- NumPy
- Pandas
- Scikit-learn
- OpenCV
- Matplotlib
